# war_correspondents_2
The repository for the course "From data to knowledge: introduction to data analysis using Linked Open Data (LOD)" (SP 2026).

## Overview
This project performs a historiographical analysis on the life trajectories and scientific work of war-correspondents and war-photographers using data from Wikidata.

## Live Demo
The results of the analyses are available on this webpage: https://camilladm.github.io/war_correspondents_2/
